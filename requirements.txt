# Nebula Systems Installer - runtime dependencies
#
# The bootstrap runs on Ubuntu's stock Python and supplies a temporary managed
# interpreter when that Python is older than 3.10. The installer deliberately
# has NO third-party Python dependencies.
#
# Everything it needs comes from the standard library:
#   argparse, getpass, json, pathlib, secrets, shutil, socket,
#   sqlite3, subprocess, urllib, grp, pwd
#
# Host tools are installed and version-checked automatically:
#   git      - fetching component repositories
#   sudo     - installing systemd units
#   systemctl / journalctl - service management
#   docker   - container runtime checks
#   node, npm - building Nebula Panel
